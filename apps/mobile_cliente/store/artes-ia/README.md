# Artes geradas — app do cliente

Oito propostas geradas por IA a partir dos screenshots correspondentes em `../screenshots`, com ambientação automotiva azul. Os arquivos foram apenas redimensionados para exportação e não substituem as capturas originais.

**Revisão antes de publicar:** a ferramenta redesenhou a interface; ela não preserva os pixels, os textos e os dados com fidelidade garantida. Compare cada arte com a versão real do app. As imagens são propostas visuais, não screenshots originais. Para uma listagem precisa, priorize as capturas reais. Os arquivos foram ampliados de 941 × 1672 para 1080 × 1920 px em PNG RGB; a ampliação não adiciona detalhes nem garante aprovação. Consulte as [orientações de screenshots do Google Play](https://support.google.com/googleplay/android-developer/answer/9866151?hl=pt-BR).

Prompt resumido: editar individualmente cada captura para uma arte vertical de um único app, manter a tela inteira e seus textos, acrescentar fundo automotivo discreto em azul-marinho e azul luminoso, sem novas marcas, textos ou telas. Gerado pela ferramenta integrada de imagens.
