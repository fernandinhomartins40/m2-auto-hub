# Materiais da Play Store — app do mecânico

- `icone-ia-512.png`: ícone 3D gerado para o mecânico (512 × 512).
- `destaque-ia-1024x500.png`: gráfico de destaque gerado para o mecânico (1024 × 500).
- `screenshots/`: cinco capturas originais da experiência do mecânico.
- `artes-ia/`: seis propostas geradas a partir das capturas, com fundo de oficina; uma é alternativa da tela de revisões. Consulte o README dessa pasta antes de usá-las.
- `icone-512.png` e `destaque-1024x500.png`: materiais anteriores, mantidos como alternativa.

As artes geradas redesenham a marca ou as telas; confira a fidelidade à logo oficial e à experiência real antes do envio. Para screenshots, priorize as capturas reais. O formato adequado não garante aprovação pela Google Play.
