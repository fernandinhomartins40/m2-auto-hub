# Paridade: PWA comparado com os apps nativos

Conferência feita em 12/11/2026 pelo agente A7 (tarefa 3.12), lendo o código do PWA e a tela Flutter lado a lado. Sem emulador e sem site rodando: as diferenças visuais finas ficam para o A9.

Como ler:

- **Igual**: mesmo conteúdo, textos, ordem e ações. Pequenos acréscimos do app que não tiram nada do PWA (confirmação antes de ação destrutiva, puxar para atualizar) contam como igual.
- **Diferença aceita**: decisão já documentada pelo dono (lista no fim).
- **A corrigir**: falta algo do PWA, ou o app mostra algo diferente sem decisão registrada.

Caminhos curtos: `pwa/` = `apps/frontend/src/components/`, `cli/` = `apps/mobile_cliente/lib/features/`, `mec/` = `apps/mobile_mecanico/lib/features/`, `core/` = `packages/mobile_core/lib/src/`. Linhas aproximadas.

Na largura de celular o PWA usa o layout móvel (`useIsMobile`, até 768 px): `CustomerLayout` com `BottomNavigation` e `MobileDrawer` no cliente, e `StoreLayout` móvel no mecânico. As comparações abaixo consideram só o que aparece nessa largura.
